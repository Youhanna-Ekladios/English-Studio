# Modern English Studio

Modern English Studio is a cinematic learning environment for understanding, practising, and using modern English.

## Open the app

Open [`Modern English Studio/Modern English Studio.html`](Modern%20English%20Studio/Modern%20English%20Studio.html) in a web browser.

Keep the `Modern English Studio_files` folder beside the HTML file. It contains locally saved styling and supporting resources. The saved page also loads parts of the app from the hosted site, so an internet connection may be required for full functionality.

## Project structure

```text
Modern English Studio/
├── Modern English Studio.html
└── Modern English Studio_files/
    ├── index-CyT8oVUV.css
    └── saved_resource.html
```

## Live app

[Open Modern English Studio online](https://modern-english-studio.youhanna-amir.chatgpt.site/)

## Updating this repository

When a newer app export is provided, copy the HTML file and its matching asset folder into `Modern English Studio/` together so their relative links remain intact.
