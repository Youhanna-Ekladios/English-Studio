# Modern English Studio

Modern English Studio is a cinematic learning environment for understanding, practising, and using modern English.

## About

This repository is the home of the Modern English Studio app and its future source files, documentation, and releases.

## Live app

[Open Modern English Studio](https://modern-english-studio.youhanna-amir.chatgpt.site/)

## Local app export

To use a saved browser export:

1. Download `Modern English Studio.html` together with its matching `Modern English Studio_files` folder.
2. Keep both items in the same directory.
3. Open the HTML file in a modern web browser.

The saved export may still load parts of the app from the hosted site, so an internet connection may be required for full functionality.
